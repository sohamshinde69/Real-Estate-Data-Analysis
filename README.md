# Real-Estate-Data-Analysis
This dataset orignally contained 1054159 rows and 11 columns and after cleaning it had 658083 rows and  9 columns .Instead of just forcing ML models I analyzed the dataset carefully and found out there is nothing currently anything useful available that I can use ML models on eg in my previous project [Retail Store Sales dataset ] I used ML models to predict the discount applied column because it had high null values in it 
<br>
<h2>Goal </h2>
<br>
Orignally the goal was to clean the data and use ML models to predict the relevent columns when necessary but when I cleaned the data i realized there is nothing useful that can be predicted . So I changed the approach from making a ML project too showing my skills in handling big messy real world data
