# Real-Estate-Data-Analysis
This dataset orignally contained 1054159 rows and 11 columns and after cleaning it had 658083 rows and  9 columns .Instead of just forcing Ml models i analized the dataset carefully and found out there is nothing current available useful that i can use ML models on eg in my previous project [Retail Store Sales dataset ] i used ML models to predict the discount applied column because it had high null values in it 
<br>
<h2>Goal </h2>
<br>
Orignally the goal was to clean the data and use ML models to predict the relevent columns when necessary but when i cleaned the data i realized there is nothing usefull thet can be predicted . So i changed the approach from making a ML project to showing my skills in handeling big messy real world data
